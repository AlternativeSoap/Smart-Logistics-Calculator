# ⌨️ Keyboard Shortcuts Guide

## ABC & EOQ Dashboard - Power User Features

### Quick Navigation

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Alt + D` | **Dashboard** | Jump to Dashboard overview |
| `Alt + A` | **ABC Analysis** | Open ABC Analysis tab |
| `Alt + W` | **Wilson EOQ** | Open Wilson calculator |
| `Alt + S` | **Settings** | Open Settings panel |

### File Operations

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + U` | **Upload File** | Opens file picker dialog |
| `Ctrl + E` | **Export Excel** | Download results as XLSX |

### Why Use Keyboard Shortcuts?

✅ **Speed:** Navigate 3x faster than using mouse  
✅ **Efficiency:** Keep hands on keyboard  
✅ **Professionalism:** Power-user workflow  
✅ **Accessibility:** Alternative to mouse navigation  

### Tips for Best Experience

1. **Learn One at a Time**
   - Start with `Alt + A` (ABC Analysis)
   - Add `Ctrl + U` (Upload) next
   - Master `Ctrl + E` (Export) last

2. **Create Workflow Chains**
   - `Ctrl + U` → Upload file
   - `Alt + A` → Switch to ABC tab
   - `Ctrl + E` → Export results

3. **Use with Drag & Drop**
   - Drag file to upload zone
   - Hit `Alt + D` to see Dashboard
   - Use `Ctrl + E` when ready to export

### Platform Differences

#### Windows / Linux
- Use `Ctrl` for Ctrl shortcuts
- Use `Alt` for Alt shortcuts

#### macOS
- Use `⌘ Cmd` instead of Ctrl
- Use `⌥ Option` instead of Alt

### Advanced Usage

**Rapid Analysis Workflow:**
```
1. Ctrl + U          (Upload)
2. Alt + A           (Go to ABC tab)
3. Click "Analyze"   (Process)
4. Ctrl + E          (Export)
```

**Compare Two Periods:**
```
1. Alt + C           (Compare tab)
2. Drag file 1       (Period 1)
3. Drag file 2       (Period 2)
4. Click "Compare"   (Run)
```
