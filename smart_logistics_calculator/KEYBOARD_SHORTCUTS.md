## Budget Editor - Power User Features

### Basic Shortcuts

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + Z` | **Undo** | Undo last change |
| `Ctrl + Y` | **Redo** | Redo last undone change |
| `Ctrl + S` | **Save** | Save budget (auto-saves anyway) |
| `F1` | **Help** | Show help dialog |
| `Escape` | **Close** | Close any open modal/dialog |

### Adding Rows

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + N` | **New Income** | Add new income row |
| `Ctrl + E` | **New Expense** | Add new expense row |
| `Ctrl + Shift + C` | **Income Category** | Add income category |
| `Ctrl + Shift + X` | **Expense Category** | Add expense category |

### View & Navigation

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Alt + M` | **Month View** | Switch to single month view |
| `Alt + F` | **Full View** | Switch to full year view |
| `Alt + S` | **Search** | Focus search field |

### Export & Import

| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + Shift + E` | **Export Excel** | Export budget to Excel |
| `Ctrl + Shift + I` | **Import** | Show import dialog |

## Why Use Keyboard Shortcuts?

✅ **Speed:** Navigate 3x faster than using mouse  
✅ **Efficiency:** Keep hands on keyboard  
✅ **Professionalism:** Power-user workflow  
✅ **Accessibility:** Alternative to mouse navigation  

### Tips for Best Experience

1. **Learn One at a Time**
   - Start with `Ctrl + N` (Add Income)
   - Add `Ctrl + E` (Add Expense) next
   - Master `Ctrl + Z` / `Ctrl + Y` (Undo/Redo) for safety

2. **Create Workflow Chains**
   - `Ctrl + Shift + C` → Add category
   - `Ctrl + N` → Add income items
   - `Ctrl + S` → Save

3. **Budget Power User Flow**
   - `Alt + M` → Switch to month view
   - Edit your numbers
   - `Ctrl + Shift + E` → Export to Excel

### Platform Differences

#### Windows / Linux
- Use `Ctrl` for Ctrl shortcuts
- Use `Alt` for Alt shortcuts

#### macOS
- Use `⌘ Cmd` instead of Ctrl
- Use `⌥ Option` instead of Alt
